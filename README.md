# aaradhya-enertech-web

Official website source code for [Aaradhya Enertech Industries](https://www.aaradhyaenertech.com/).

## Overview
A modern, mobile-responsive website showcasing transformer sales, parts supply, and electrical maintenance services in Jaipur, Rajasthan.

## Tech Stack
- HTML5
- CSS3 (`styles.css`)
- Vanilla JavaScript (`script.js`)
